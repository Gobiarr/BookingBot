# 📅 BookingBot — Telegram-бот для онлайн-записи

Telegram-бот для автоматизации записи клиентов на услуги. Подходит для барбершопов, салонов красоты, частных мастеров и других специалистов, работающих по предварительной записи.

## ✨ Возможности

### 👤 Для клиентов
- 📋 Просмотр доступных услуг и цен.
- 📅 Выбор услуги, даты и свободного времени.
- 📝 Оформление записи с указанием имени и телефона.
- 🗓 Просмотр своих записей.
- ❌ Отмена будущих записей.

### 🛠 Для администратора
- 🔐 Доступ к панели администратора.
- ➕ Добавление новых услуг.
- 💰 Изменение стоимости услуг.
- 🔄 Включение и отключение услуг.
- 📋 Просмотр предстоящих записей.

### ⚙️ Технические особенности
- Python и aiogram 3.
- SQLite для хранения данных.
- Асинхронная обработка сообщений.
- FSM для управления этапами записи.
- Проверка доступности времени.
- Хранение настроек в `.env`.

## 🧰 Технологии

## 🚀 Установка и запуск

### 1. Клонирование проекта

```bash
git clone https://github.com/Gobiarr/BookingBot.git
cd BookingBot
```

### 2. Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создай файл `.env` в корневой папке проекта по примеру `.env.example`.

Укажи в нём:

```dotenv
BOT_TOKEN=токен_твоего_бота
ADMIN_ID=твой_telegram_id
```

**Не публикуй файл `.env` и не передавай токен бота посторонним.**

### 5. Запуск бота

```bash
python bot.py
```
